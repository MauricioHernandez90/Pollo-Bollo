# Pollo Bollo - Web Oficial 🎪

Maqueta web en React + Vite + Tailwind para el payaso Pollo Bollo / Bollo El Tx8

## Instalación

```bash
npm install
npm run dev
```

## Build producción

```bash
npm run build
```

## Estructura

- /src/App.tsx -> Toda la web en un solo componente (hero, paquetes, modales, contacto)
- /src/assets -> 8 imágenes optimizadas del show
- /src/index.css -> Tailwind + animaciones (confeti, burbujas, float)

## Paquetes incluidos

1. Show Pollo Bollo (familiar)
2. Show Adultos Tx8
3. Baby Shower
4. Paquete Plus - Experiencia Total
5. Navideño Familiar
6. Navideño Adultos

Todos con modal de detalles completo.

Cambia el número de WhatsApp en App.tsx -> handleWhatsApp() y footer.
